# Bank Microservices

Sistema bancário baseado em microsserviços desenvolvido com Java 21 e Spring Boot.

## Arquitetura

- auth-service
- customer-service
- account-service
- transaction-service
- bank-security

## Tecnologias

- Java 21
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Flyway
- Docker
- MapStruct
- Swagger

## Como executar

docker compose up -d
